AVERAGE PERFORMANCE

Hashing:
20 / 8 = 2.5 operations

Linear Search:
36 / 8 = 4.5 comparisons


PERFORMANCE COMPARISON

Hashing has fewer observed search operations for
the given song IDs.

Hashing Average Complexity:
O(1)

Linear Search Average Complexity:
O(n)

However, collisions can increase the search operations
in hashing.
